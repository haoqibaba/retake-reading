# AI 邪修 · 重建孩子阅读习惯

用 AI 把孩子爱看的视频，变成一份带拼音的、可以打印的读物。
**读完这一篇，才准看这一集。**

## 这套方法叫什么

| | |
|---|---|
| **方法** | **AI 邪修** —— 不跟孩子的逆反正面硬碰，绕到他最爱的地方，从侧面切进去 |
| **概念** | **读视频** —— 视频本来是看的，偏让他读；把视频读成一篇字 |
| **目标** | **重建阅读习惯** —— 把阅读装回他的日常 |

「邪」不是坏，是**偏门**：用偏门的路子，办正经的事。

### 为什么是「重建」，不是「培养」

「培养」是从无到有，是学校的语汇，默认孩子肚子里什么都没有。

「重建」承认另一件事：这个习惯本来有，只是后来塌了。小学低年级的孩子大多能捧着书看半天，是后来被读题、被要求、被比较，一点点磨没的。

所以我们不是在从零教他读书，而是在把它重新盖起来。这个区别很重要——它不指责孩子懒，也不指责家长没做好，只说明一个事实：塌了，那就重新盖。

写稿、讲这套方法时，用「重建」，别用「培养」。

一句话讲清：**不去逼他读书，而去改造他已经在看的东西。**

它解决的是一个具体问题：孩子不爱读文字，但爱看视频。那就换个顺序——先读文，再看片。阅读不再是任务，而是拿到喜欢内容的一道门。

> 对外统一叫「AI 邪修」「读视频」。这是同音词，与修仙文的「邪修」一样，是有意为之；上镜用一句「不是修仙那个邪修，是偏门的路子」即可立住。

## 完整工序

### 第 1 步：拿到最准的原文（字幕优先）

1. **先找字幕。** B 站可查 `https://api.bilibili.com/x/player/v2?aid=<aid>&cid=<cid>` 的 `subtitle.subtitles`。能拿到就直接用——字幕比语音识别准得多。
   - ⚠️ **接口返回空，不代表视频没有字幕**（未登录时常返回空）。不要据此下结论。先看播放器有没有字幕按钮；判断不了就请用户导出 `.srt` / `.txt`。
2. **没有字幕再转写。** 用任意 ASR（火山引擎、Whisper 等）。
3. 原始稿先存档，别覆盖。

> 拿到字幕后**必须逐句对校**：ASR 最容易错在型号数字（波音 777→717）、人名地名、说话人身份、专业术语。

### 第 2 步：改写成文章

整理成有标题、有小节、有自然段的完整文章。

**只删这三类：**

1. **频道口播词**：「大家好我是XX」「我们下次见」「感谢观看」。
2. **开场没有画面感的流行梗**——孩子读不懂、又想象不出画面的类比。例如「柯南里是波音747」「显卡圈里的核弹 GTX690」「汽车圈的保时捷911」「背木兰辞接的还是波音747」。
3. **纯互动话术**：「你们觉得呢」「评论区聊聊」「点个关注」。

**其余内容尽量全部保留**——各型号的来龙去脉、设计原理、数字细节、有趣的轶事，这些才是孩子愿意读下去的东西。

> **留存率目标 95%–100%。** 不要为了「简洁」把内容压掉一半。压得太狠，孩子读完什么也没得到。这一条被明确纠正过：第一版压到 69%，被否。

**顺手做：**

- 修错别字、统一专名（同一架飞机、同一个人全文一个写法）
- 专业词首次出现给一句白话解释（FAA → 美国联邦航空管理局）
- 长句拆短，一段只讲一件事
- 小节标题制造悬念：「它本来是一架货机」「为什么还在用钢索？」

**不许编造。** 数字、时间、情节必须来自原文；拿不准的就不写。

### 第 3 步：写成 JSON

只支持三种块：

```json
{
  "blocks": [
    {"kind": "title", "text": "主标题"},
    {"kind": "title", "text": "——副标题"},
    {"kind": "h2",    "text": "小节标题"},
    {"kind": "p",     "text": "自然段……"}
  ]
}
```

- `title` 可连续写两块，渲染成两行居中标题
- 标点、数字、英文字母不注音，脚本自动跳过

范例：`assets/范例-article_source.json`

### 第 4 步：生成 Word

```bash
pip install pypinyin python-docx        # 首次运行需要
python3 scripts/build_pinyin_docx.py 文章.json -o 孩子的读物.docx
```

词表会自动从 `assets/多音字词表.json` 加载（60 条常见纠正）。也可以 `--phrases 其他词表.json` 追加。

脚本自动完成：逐字注音 → 生成 Word 拼音指南（ruby）→ 字体替代映射（楷体→汉仪楷体简）→ **文本完整性校验** → 输出逐字拼音审查稿。

### 第 5 步：检查拼音（不能省）

脚本会打印「易错字抽查」列表（`watch: ...`），逐个看。重点：

- 多音字：长（cháng/zhǎng）、得（de/dé）、处（chǔ/chù）、应（yīng/yìng）、为（wéi/wèi）、着（zhe/zhuó）
- **词组误匹配**：pypinyin 会把「之后的哥伦比亚」读成「的哥 dī」、「还给」读成 huán、「中都」读成 dū——遇到这种，**改文本比加词条干净**
- 新人名、地名、型号逐个核对

审查稿在输出 docx 旁边（`拼音审查稿.txt`），可逐字检查。发现问题补进词表再重跑。

## 最终格式（家长认可过，照这个来）

| 项目 | 标准 |
|---|---|
| 汉字 | 楷体 |
| 拼音 | Times New Roman |
| 字号 | 正文 20 磅 / 拼音 8 磅；小标题 22/10；标题 24/11 |
| 拼音对齐 | 居中、**自然字距**（绝不用「分散对齐」，否则 `bù` 会被拉开、`cháng` 会被挤扁） |
| 行距 | **全篇单倍行距**（打印实测：多倍行距反而太散） |
| 页码 | 每页页脚居中自动编号 |
| 页面 | A4，正文左对齐 + 首行缩进 2 字 |

**一定要用 WPS 或 Word 打开**：系统自带的快速预览不显示拼音层，不要以为拼音丢了。

## 规矩：别把这件事做成作业

读完就是读完。不用写读后感，不用回答问题，不用复述。

**规则只有一条：读完这一篇，才能解锁这一集视频。**

孩子认这套，是因为它在交换，不是在管教。

## 常见问题

**拼音被拉得很开 / 挤成一团？**
Word 拼音指南默认「分散对齐」会按汉字宽度拉伸拼音。必须用 `rubyAlign="center"`（本脚本已内置）。

**打开看不到拼音？**
用 WPS / Word 打开。Mac 快速预览（空格键）不显示拼音层，属正常。

**文件变大、拼音变成奇怪的域代码？**
WPS 另存后会把拼音转成 EQ 域，显示不受影响。想要干净原版，用脚本重新生成。

**楷体显示不出来？**
Mac 系统没装楷体。脚本已在 fontTable 加「楷体 → 汉仪楷体简」替代映射，WPS 自带该字体。

```
读视频 · 第 01 期：阿罗哈航空 243 号班机（空难）
```
